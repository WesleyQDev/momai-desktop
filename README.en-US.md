# MomAI Desktop (Extension)

This extension allows MomAI to open programs, applications, and folders directly on your computer — and automate tasks by clicking and typing on buttons by name.

### What it does for you:
*   **Open Programs**: Start any application by name (e.g., "open Chrome", "start Spotify").
*   **Find Folders**: Quickly open directories on your computer (e.g., "open my Downloads folder").
*   **Automate the screen**: Ask it to click a button or type into a field by name — e.g., "click Save".
*   **Visible step by step**: Every run shows a compact card in chat, with a button to the full timeline on the extension page.
*   **Screenshots as files**: Ask for a screenshot of the current monitor, of another monitor, or of one program window — the image is saved as a file and only appears in chat when you want to see it. You can show it, keep it, or attach it to an e-mail.
*   **Safety controls**: Approval mode for each click, allowed-apps list, and a stop button at any time.
*   **Automatic Search**: It looks in common locations where your programs are usually installed so you don't have to type the full path.

### Examples of what to ask:
- "Open the Google Chrome browser."
- "Start Visual Studio Code in my documents folder."
- "Open the Pictures folder."
- "Run the calculator."
- "Click Save in Notepad."
- "Take a screenshot of the Notepad window and show it to me."
- "Take a screenshot of display 2 and attach it to an e-mail."
- "What have you done so far?"

### Security:
This extension only acts on items you explicitly request and respects your Windows user permissions. If it finds more than one program with a similar name, it will ask which one you want to open. Screenshots, replay captures and preferences stay on your computer; screenshots are temporary and old ones are deleted automatically. When you ask it to describe the screen, that image is sent to the AI model active in MomAI — local or cloud, depending on your configuration.
